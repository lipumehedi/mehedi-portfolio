# MD Mehedi Hasan — Portfolio Website

A responsive personal portfolio built with HTML, CSS, and a little JavaScript.

## Files

- `index.html` — page content and sections
- `style.css` — colors, layout, cards, and responsive design
- `script.js` — mobile navigation and current footer year
- `profile.jpg` — add your own photo here

## Run it

1. Extract the ZIP file.
2. Put your own photo in this folder and name it `profile.jpg`.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Before publishing

Check each GitHub project link in `index.html` and replace any general GitHub profile links with the exact repository URL if needed. Update any content you want to change.
