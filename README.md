## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/lipumehedi/mehedi-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd mehedi-portfolio
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
